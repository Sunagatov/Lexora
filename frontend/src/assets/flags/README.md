Noto Color Emoji, flag-only subset obtained from the Google Fonts API.

Contains only the nine country flags used by the language selectors. Bundled locally so Windows Chrome can render flag emojis, including offline.

Subset name: Lexora Flags. Only the requested flag ligatures and their COLR vector layers are retained; the duplicate SVG table is removed. Adding a different country flag requires updating this subset. Vite includes the font in the service worker's cached assets.

License: SIL Open Font License 1.1; see OFL.txt.

The nine 64px PNGs are rendered from this font for browser-tab icons. They use
the same flags as the language catalog and work without platform emoji support.
Vite bundles them with the offline shell.
Upstream: https://github.com/googlefonts/noto-emoji
API documentation: https://developers.google.com/fonts/docs/getting_started#optimizing_your_font_requests
