# 🇹🇷 Lexora — Турецкое произношение русскими буквами

**Турецкий (Турция, tr)** · **русские переводы (ru)** · **500 уникальных Word ID** · **20361–20860**.

## 1. Назначение

Подсказки предназначены для русскоязычного ученика. Поле `pronunciation_easy` содержит **приблизительную русскую кириллицу с ударением**. Это не IPA и не проверенное аудио. Исходная турецкая форма сохранена в `term` без изменений.

## 2. Произношение и условная запись

| Турецкая буква | Звук | Русская подсказка | Ограничение |
|---|---|---|---|
| c | /dʒ/ | дж | два русских знака передают один аффрикатный звук |
| ç | /tʃ/ | ч | близкая пара |
| ş | /ʃ/ | ш | близкая пара |
| j | /ʒ/ | ж | заимствованные слова |
| ı | /ɯ/ | ы | турецкий звук отличается от русского «ы» |
| i | /i/ | и | не путать с ı |
| ö | /œ/ | ё | приблизительно; при сочетании с согласной может смягчить её по-русски |
| ü | /y/ | ю | приблизительно; это один передний огублённый гласный |
| ğ | изменение длительности/переход гласных | отдельной буквы нет | НЕ произносить как «г», обязательно слушать аудио |
| y | /j/ | й | звук-переход |
| e | /e~ɛ/ | э | без характерного русского смягчения |
| h | /h/ | х | русский «х» более задний/шумный |

Ударная гласная помечена комбинируемым знаком `́`: `гюнайды́н`. Турецкий по умолчанию часто имеет ударение на последнем слоге, но существует немало исключений: заимствования, географические названия, наречия, некоторые аффиксы и другие лексемы.

## 3. Фонетические ограничения и особые слова

- **merhaba** — нестандартное распределение ударения; следует подтверждать словарным звучанием.
- **banka, taksi, sandalye** — заимствованные слова со сложным ударением; помечаются `needs_review`.
- **hayır, yarın, şimdi, lütfen** — возможное неоконечное ударение; ручная проверка необходима.
- **ağrı, yağ, dağ, değil, doğum** — наличие `ğ`: обычная замена буква-в-букву не работает.
- **Wi‑Fi** — заимствованная латинская аббревиатура с не полностью турецким чтением.
- Чтение `e` как «э», `ö` как «ё» и `ü` как «ю» — **учебная договорённость**, не точная передача IPA.
- Для фраз отдельно оценивайте произношение в слитной речи и служебные слова.

## 4. Проверка и статусы

Обработано **500** уникальных Word ID. **382** записей получили предварительные кириллические подсказки без специфических обнаруженных исключений, **118** помечены `needs_review` по признакам сложности ударения, `ğ`, необычной орфографии или неясного прочтения.

`ready` означает **только отсутствие выявленного алгоритмического конфликта**; это не означает проверку носителем. **Импорт пока не одобрен** (`approved_for_import=false`).

## 5. Передача Codex

1. Сопоставить `word_id`, `language=tr`, исходные `term` и `part_of_speech` с экспортом. Записи из других языков не обрабатывать.
2. Не изменять существующие IPA, аудио, переводы, определения, темы, пользовательский прогресс и другие данные.
3. Убедиться, что схема поддерживает Cyrillic `russian-cyrillic-v1` для турецкого — **не подменять стандартное латинское турецкое написание**.
4. Проверить словарный звук и ударение для всех `needs_review` и репрезентативно для `ready`. Запрещено импортировать всё только по `ready`.
5. Сверить SHA256 входного Excel и выходного JSONL с manifest.json. Импорт только после одобрения.
