# 🇫🇷 Lexora — французское произношение для русскоязычного учащегося

**Норма:** французский язык Франции (fr-FR). **Экспорт:** `lexora-vocabulary (5)(2).xlsx`; скрытый `_Lexora_Language`: `language=fr`, `translation_language=ru`. **Слова:** 500, IDs 19361–19860.

## 1. Метод и ограничение

Подсказки на кириллице с ударением, выведенные из автоматически полученного IPA eSpeak fr-FR и правил передачи французских звуков на русский. eSpeak — синтезатор речи, **не** словарь или замена записи носителя; алгоритмические допущения могут содержать ошибки. Ударение во французском преимущественно ритмико-групповое, а не жёстко словарное; отметки в длинных фразах являются лишь ориентиром.

**Данные НЕ утверждены для импорта.** 402 временно отмечены ready; 98 требуют проверки; все 500 не подтверждены аудио носителя. Кодексы и приложения должны смотреть `verification.approved_for_import=false`, а не только `status=ready`.

## 2. Французские звуки, которые русский алфавит передаёт неточно

- **Носовые гласные** [ɑ̃, ɔ̃, ɛ̃, œ̃] — приблизительно «ан», «он», «эн», «ён». Это один гласный звук, **не отдельная н**! Например `bon → бон` (носовое о) и `pain → пэн` (носовое э). В реальном французском различия важны.
- **u** (французское /y/) — передний округлённый гласный; приблизительная «ю» может ошибочно смягчать согласную. Пример `salut → салю́`.
- **eu / œu** /ø, œ/ — округлённые передние гласные; условное «ё» не является точным эквивалентом. Пример `sœur → сёр`.
- **r** /ʁ/ — заднеязычный/увулярный, а не привычное русское раскатистое «р»; условно пишем «р».
- **ch** /ʃ/ обычно «ш»; **j** /ʒ/ — «ж»; **gn** /ɲ/ — «нь».
- Многие **конечные буквы не читаются** (`petit`, `grand`), а в **liaison** в некоторых контекстах согласная неожиданно появляется (`les amis`). В сочетаниях и фразах нужен контекст.
- **e caduc** /ə/ (неустойчивое e) может произноситься, сокращаться или выпадать, например в `je`, `de`, `semaine`.
- **Акценты** не означают русское ударение. Акцент в подсказке отмечает лишь ориентировочное место выделения по произнесению eSpeak.

## 3. Примеры условной системы

| Французское слово | Учебная кириллическая подсказка | Комментарий |
| --- | --- | --- |
| salut | салю́ | Французский /y/ ≠ русское ю |
| bonjour | бонжу́р | носовой гласный /ɔ̃/ |
| merci | мэрси́ | увулярное /ʁ/ условно «р» |
| eau | о | одна гласная несмотря на три буквы |
| fille | фи́й | -ille не «илле» |
| femme | фа́м | исключение, не «фемме» |

## 4. Как устроен пакет

- `lexora-fr-cyrillic-pronunciation.jsonl`: одна строка на Word ID; `pronunciation_easy` заполнено только для предварительных `ready`; `null` для `needs_review`.
- `lexora-fr-pronunciation-proposals.jsonl`: черновые чтения **всех 500**, автоматический IPA, перевод, контекст и причины review.
- `lexora-fr-needs-review.csv`: список неоднозначных случаев.
- `lexora-fr-pronunciation-review.xlsx`: полный таблица для лингвиста + вкладка review.
- `lexora-fr-pronunciation-manifest.json`: SHA256 входных/выходных файлов, точные подсчёты и запрет автоимпорта.
- Google Doc: **все 500** исходных записей + предложенные чтения + флаги.

## 5. Критерии утверждения

Проверить записи, особенно nasal vowels, e caduc, liaison, elision, французское /ʁ/, /y/, /ø/, /œ/, неоднозначные consonnes finales и ударение в длинных выражениях, по надёжным источникам с аудио. Важно отделить IPA/транслитерацию и поле easy pronunciation, не перетирать звук, переводы, связи и прогресс.
