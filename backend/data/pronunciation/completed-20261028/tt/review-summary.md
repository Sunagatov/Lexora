# Tatar held-readings review — 28 October 2026

Reviewed the 41 currently held Word IDs against their actual meanings, parts of
speech, source proposals and grammatical structure. `tt-resolved.json` contains
41 ready approximate reading aids, preserving Tatar Cyrillic, with individual
reasons and references. No IDs, meanings or learning progress are changed.

This is accented native spelling, not full IPA or forced ordinary-Russian
respelling. Distinctive ә/ө/ү/ң/һ are retained and explained. Phrase-level emphasis
can vary. No individual native recordings were verified.

Important corrections/context resolutions:

- күреше́рбез: future-tense -ер is stressed, personal -без is not.
- хәлләреге́з / исемеге́з: these are possessive nouns, **not** imperatives merely
  because the endings resemble imperative -гез.
- танышуыбызга́ ша́тмын: a nominal dative plus a copular/personal predicate;
  the personal -мын does not become tonic.
- и́тегез / би́регез / ча́кырыгыз: second-person imperatives, initial stress.
- кабатлы́й а́лмассызмы: do not shift stress onto negation/person/question suffixes.
- ка́рта, телеви́зор, ста́нциясе, аллерги́ям: source-stress-retaining recent loans;
  do not apply a final-vowel accent blindly. броньлады́м is an inflected Tatar
  verb with positive past-tense morphology, not the same stress class as
  a Russian multi-syllabic noun with a nonfinal tonic vowel.
- салкы́нча: primary teacher phonetic analysis explicitly identifies its second
  syllable as tonic.
- һә́ркем: the native Magarif teaching table explicitly puts it in the
  first-syllable group.
- иртәнге́: the official 11th-grade olympiad answer explicitly identifies the
  third/final syllable as tonic.

One deliberate limit: ID 21357 is `вайфай ба́рмы?`. **No unverified lexical accent
is assigned to the international Wi-Fi loan.** The actual syllables remain
recognizable to a Russian reader, and the per-word note makes this limitation
explicit; established question бар-мы is accented correctly. This resolves the
usable reading without pretending to have established one Tatar loanword stress.
If a strict all-words-accented dataset is required, this one accent still needs
lexical/native confirmation.

Paired-word stress has variation across teaching sources. For хатын-кыз the
selected contemporary source explicitly gives хатын-кы́з, consistent with the
scheme chosen in the previous import. This is not a claim that every possible
focus contour or older paired-word generalization is identical.
