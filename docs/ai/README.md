# Lexora AI context index

These files are meant to help coding assistants work with **less context**, fewer repeated explanations, and lower token cost.

## Files

- `repo-map.md` — compact repo structure and where to look first
- `architecture.md` — high-level backend/frontend flow
- `api-surface.md` — confirmed routes and contracts
- `env-reference.md` — important configuration knobs
- `change-playbook.md` — task-to-file lookup and safe workflow
- `context-budget-rules.md` — explicit context-minimisation rules
- `prompt-templates.md` — ready prompts for Claude/Cloudy/Copilot-style tools
- `ai-cost-reduction-backlog.md` — practical backlog for making Lexora’s AI features cheaper and faster
